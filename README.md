# Fieldworx Ordering Platform

Created for restaurateurs to order directly from suppliers using the website as a middleman.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## What’s included

- Landing page for **Fieldworx**
- Supplier browse + catalogue pages with sample South African trade products
- Draft order flow (stored in the browser for this demo)
- How it works overview

Prices are sample ZAR amounts for demonstration only.
